# ממיר MP4 לתאימות Canon ו-Android

אפליקציית Android להמרת סרטונים לקובץ MP4 חדש באמצעות AndroidX Media3 Transformer.

## פרופיל
- וידאו H.264 / AVC
- שמע AAC
- עד 1080p
- שמירה בתיקיית Movies/MP4 Converter ב-Android 10 ומעלה

## בנייה
GitHub Actions builds a debug APK and uploads it as an artifact on each push to main.

The app processes selected videos locally on the Android device. Compatibility with every Canon model cannot be guaranteed without the exact model.
